# Shared components

- `SiteHeader.jsx`: navigasi client-side ke route publik, menu responsif, dan kontrol tema.
- `SiteFooter.jsx`: identitas dan navigasi kembali ke beranda/atas.
- `PageIntro.jsx`: pengantar halaman dan breadcrumb untuk route internal.
- `SectionHeading.jsx`: heading seksi yang dipakai pada beranda.
- `BrandMark.jsx`: mark konseptual ORION.

Komponen bersama digunakan lintas halaman melalui `MainLayout` atau secara langsung oleh halaman.
